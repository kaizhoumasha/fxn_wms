# Suggested Commands
- `source .venv/bin/activate` – activate Python venv when running Python tooling.
- `/speckit.specify "<feature description>"` – start new feature spec and branch via agent workflow.
- `.specify/scripts/bash/create-new-feature.sh --help` – view options for feature creation script.
- `.specify/scripts/bash/check-prerequisites.sh` – verify required docs (spec/plan/tasks) exist for later phases.
- `.specify/scripts/bash/setup-plan.sh` – helper for planning phase.
- `.specify/scripts/bash/update-agent-context.sh` – refresh agent context.
- Common tooling: `ls`, `rg`, `git status`, `git fetch --all --prune`, `git branch` per workflow notes in GEMINI.md.
- No test/lint commands defined yet; repository currently doc-only.
