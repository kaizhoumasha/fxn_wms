# 休斯顿 P9 WES 项目功能列表与验收标准 (Project Function List & Acceptance Criteria)

> **文档版本**: 1.0 (Based on SRS v2.0)
> **生成日期**: 2025-12-15
> **适用范围**: 客户验收 (UAT) 与项目交付

本文档基于《软件需求规格说明书 (SRS)》及《用户需求分解》整理，旨在明确休斯顿 P9 智能仓储执行系统 (WES) 的交付功能点及验收标准。文档分为两部分：**功能验收**与**技术指标验收**。

---

# 第一部分：业务功能验收 (Functional Acceptance)

## 1. 入库管理 (Inbound Management)
**目标**: 实现从码头收货到IQC检验及上架前的标准化流程。

| 子模块 | 功能点 | 功能说明 / 验收标准 | 关联设备 |
| :--- | :--- | :--- | :--- |
| **1.1 码头收货** | **单据接入** | 自动接收上游 (SAP/WMS) 的 GRN 收货通知单，支持按 PO/料号查询。 | - |
| | **栈板标签打印** | 根据到货箱数生成唯一的栈板条码 (Pallet ID) 并驱动现场打印机打印。 | 打印机 |
| | **收货绑定 (PDA)** | 支持 PDA 扫描栈板号 + 物料条码进行绑定；支持混托与分托；校验绑定数量 $\le$ GRN 剩余数量。 | PDA |
| | **码头任务发起** | 绑定完成后，自动生成“码头 -> 收货暂存区”的搬运任务。 | PDA, RCS |
| **1.2 质量管理** | **IQC 抽检策略** | 依据 QMS 规则自动计算抽检量；若需抽检，自动生成送往 IQC 待检区的路由任务。 | - |
| | **取样与归还** | 记录 IQC 取样动作（PDA 扫描六合一码）；记录样品归还至原栈板的操作。 | PDA |
| | **检验结果同步** | 接收 QMS 的检验结果 (OK/NG)；OK 则路由至暂存区，NG 则路由至复判区。 | QMS |
| | **复判与拆板** | 支持复判区 PDA 拆板作业：将 NG 物料拆分至新栈板（不良品栈板），原栈板放行。 | PDA |

## 2. 智能装箱与内部物流 (Smart Kitting & Internal Logistics)
**目标**: 协调机械臂与AGV，实现从暂存栈板到标准料箱的自动化转换。

| 子模块 | 功能点 | 功能说明 / 验收标准 | 关联设备 |
| :--- | :--- | :--- | :--- |
| **2.1 智能装箱** | **空架补给策略** | 监控装箱区空箱位，不足时自动呼叫 RCS 从“一层货架存放区”补给空架。 | RCS |
| | **视觉识别校验** | 接收 ECS 视觉识别数据（尺寸、厚度、PKG），校验是否与当前任务 GRN 匹配。 | ECS (视觉) |
| | **智能分箱算法** | **Binning Strategy**：根据料盘尺寸（7寸/13寸/15寸）及厚度，计算最佳料箱及储位；优先合并同类物料。 | ECS (机械臂) |
| | **异常处理** | 物理装入失败（如变形、满箱）时，自动标记异常槽位并重新分配或换箱。 | ECS |
| **2.2 混合入库** | **满箱交换策略** | 若料箱使用率 $\ge$ 80%，生成“满箱交换”任务（CTU 直接整箱交换至五层货架）。 | RCS (CTU) |
| | **零散入库策略** | 若料箱未满，生成“零散拣选”任务（机械臂将料盘抓取至目标料箱）。 | ECS, RCS |
| | **A/B 面平衡** | 存储时自动平衡五层货架 A/B 面的负载，避免单侧过载。 | - |

## 3. 生产发料 (Production Supply)
**目标**: 响应 SAP 工单需求，实现精准、及时的物料配送。

| 子模块 | 功能点 | 功能说明 / 验收标准 | 关联设备 |
| :--- | :--- | :--- | :--- |
| **3.1 任务策略** | **波次计算** | 根据工单开线时间 + 6小时补料间隔（Rolling Wave）自动生成发料波次。 | - |
| | **分配策略** | **FEFO**（先失效先出）；**余料优先**（优先发零散库存）；**退料优先**（优先发退货货架物料）。 | - |
| **3.2 发料执行** | **自动线发料** | 调度五层货架/退料货架至流水线；指令 ECS 拣选指定物料至转运料架。 | ECS, RCS |
| | **人工线发料** | 针对特殊物料生成 PDA 指令，指导人工从指定货架拣选物料。 | PDA |
| | **缺料预警** | 当 ECS 反馈无法抓取或库存不足时，自动触发缺料告警并尝试搜索替代库存。 | - |

## 4. 特殊物料管理 (Special Material Handling)
**目标**: 针对高价值、敏湿、异形及结构件的定制化管控。

| 子模块 | 功能点 | 功能说明 / 验收标准 | 关联设备 |
| :--- | :--- | :--- | :--- |
| **4.1 高值/MSD** | **高值专属路由** | 高值物料不进普通暂存区，直接路由至高值区；强制校验六合一码绑定。 | RCS, PDA |
| | **MSD 时效监控** | 记录开封时间，计算剩余车间寿命；超时禁止发料。 | - |
| **4.2 机构件** | **AB 栈板协同** | 识别成对的上盖/下盖物料，强制同步调度至拆包线（时间差控制）。 | RCS |
| | **拆包与追溯** | 记录机构件 SN 码与箱号的绑定关系；推送追溯数据至 SFC。 | ECS |
| | **Magazine 调度** | 监控 Magazine 状态，满料自动呼叫搬运至产线缓存区。 | RCS |

## 5. 生产退料闭环 (Production Return Management)
**目标**: 确保产线退料经过严密检测和处理后回流库存。

| 子模块 | 功能点 | 功能说明 / 验收标准 | 关联设备 |
| :--- | :--- | :--- | :--- |
| **5.1 接收与分类** | **退料接收** | PDA 扫描退料；系统指导分类（电子料/MSD/高值/垃圾）。 | PDA |
| **5.2 测试与计数** | **LCR 测试决策** | 依据物料属性及是否满盘，判决是否需 LCR 测试；记录测试结果 (Pass/Fail)。 | LCR测试仪 |
| | **X-Ray 点数** | 对散盘进行 X-Ray 智能点数；接收并更新实际数量。 | X-Ray |
| **5.3 贴标与上架** | **智能贴标** | 生成含新数量、新日期的六合一标签 (ZPL)；ECS 贴标后自动校验。 | 打印贴标机 |
| | **分类上架** | 优先归还至退料货架（Return Rack）的精确储位；支持 A/B 面管理。 | RCS |

## 6. 系统运维与集成 (System Operation & Integration)
**目标**: 系统的“大脑”职能，保障高可用性与数据一致性。

| 子模块 | 功能点 | 功能说明 / 验收标准 | 关联设备 |
| :--- | :--- | :--- | :--- |
| **6.1 接口集成** | **北向接口** | 标准 RESTful API 对接 SAP/WMS（单据下载、库存预留、实绩回传）。 | - |
| | **南向接口** | 插件化适配器对接 RCS/ECS；支持 Modbus/TCP/HTTP 协议转换。 | - |
| **6.2 状态与监控** | **库存镜像** | 维护独立的实时库存镜像 (Inventory Mirror)，支持亚秒级查询。 | - |
| | **数字孪生** | 实时追踪每个料箱、AGV、任务的执行状态 (Pending/InProgress/Completed)。 | - |
| **6.3 异常处理** | **断点续传** | 系统重启或网络中断恢复后，任务可从上次断点处继续执行。 | - |
| | **人工降级** | 支持一键切换至“人工 PDA 模式”，生成人工任务单接管自动线业务。 | - |
| | **优先级调整** | 支持手动提升急料任务的优先级，实现插队作业。 | - |

# 第二部分：技术与非功能验收 (Technical & Non-Functional Acceptance)

## 7. 接口验收 (Interface Acceptance)
**目标**: 确保 WES 与上游 (SAP/WMS) 及下游 (RCS/ECS) 系统的通信准确、实时且具备容错能力。

| 接口类型 | 接口名称 / 场景 | 验收标准 / 技术指标 |
| :--- | :--- | :--- |
| **北向 (Northbound)** | **单据下发 (Inbound/Order)** | SAP/WMS 下发 GRN 或工单后，WES 需在 **<2秒** 内响应 ACK，并成功解析入库。 |
| | **库存查询 (Inventory Query)** | WES 调用 WMS 实时库存接口，响应时间应 **<1秒** (P95)；支持缓存策略 (TTL=30s)。 |
| | **库存预留 (Reservation)** | 发料前向 WMS 申请锁定库存，必须保证**事务一致性**，失败则不生成任务。 |
| | **实绩回传 (Confirmation)** | 物理作业完成后，WES 需在 **<5秒** 内向 WMS 回传 `Putaway_Confirm` 或 `Issue_Confirm`。 |
| **南向 (Southbound)** | **任务下发 (Dispatch)** | WES 向 RCS/ECS 下发指令的延迟应 **<500ms**；支持幂等性设计 (`idempotency_key`)。 |
| | **状态同步 (State Sync)** | WES 需实时 (<1s) 接收 RCS/ECS 的状态变更 (Started, Completed, Failed)。 |
| | **异常处理 (Error Handling)** | 硬件报错或超时时，WES 需自动重试 **3次**；重试失败后触发人工介入告警。 |
| | **心跳检测 (Heartbeat)** | WES 需每 30秒 (可配) 检测硬件在线状态；断线后自动标记设备离线并暂停分配任务。 |

## 8. 非功能性验收 (Non-Functional Requirements)
**目标**: 验证系统的性能、高可用性及可维护性。

| 维度 | 指标项 | 验收标准 |
| :--- | :--- | :--- |
| **性能 (Performance)** | **API 响应时间** | 核心业务 API (如 PDA 扫码、任务下发) 平均响应时间 **<500ms**。 |
| | **并发处理能力** | 支持 **50+** PDA 同时在线作业；支持 **100+** AGV/机器人并发调度。 |
| | **数据吞吐量** | 系统需支持日均 **5000+** 订单行 (Order Lines) 的处理能力。 |
| **可靠性 (Reliability)** | **系统可用性** | 核心服务可用性目标 **99.9%** (月度停机时间 < 43分钟)。 |
| | **独立运行能力** | **断网生存 (Offline Mode)**: 与 SAP/WMS 断网时，WES 必须能独立指挥现场设备完成已下发任务，并缓存实绩数据待网络恢复后上传。 |
| | **数据一致性** | 任何异常中断（断电、重启）后，系统重启必须能恢复任务状态，**数据零丢失**。 |
| **安全性 (Security)** | **接口认证** | 所有 API 调用需通过 Token/API Key 认证；敏感数据传输需加密 (HTTPS)。 |
| | **操作审计** | 关键操作 (如库存调整、任务强制取消) 必须有完整的审计日志 (Who, When, What)。 |
| **可观测性 (Observability)** | **监控大屏** | 提供 Grafana/Dashboard 实时展示：当前任务数、设备在线率、API 错误率、库存水位。 |
| | **日志查询** | 提供集中式日志检索功能，支持按 TaskID 全链路追踪 (Traceability)。 |

## 9. 部署与灾备验收 (Deployment & DR)
**目标**: 确保系统架构符合边缘计算要求，且具备快速恢复能力。

| 项目 | 内容 | 验收标准 |
| :--- | :--- | :--- |
| **容器化部署** | **Docker 交付** | 所有服务 (App, DB, Redis, Worker) 均以 Docker 镜像交付；提供 `docker-compose` 或 K8s 编排文件。 |
| **数据库** | **读写分离** | (可选) 验证高并发下 Redis 缓存与 PG 数据库的一致性策略。 |
| **备份恢复** | **数据备份** | 数据库需配置自动定时备份 (如每日凌晨)；验证备份文件可成功恢复系统。 |
| **环境适应** | **边缘服务器** | 验证系统可在指定的边缘服务器配置 (如 8C/16G) 上稳定运行。 |

## 附录：核心业务流程图 (关键路径)
*(验收时需对照实际操作演示)*

1.  **入库 (Inbound)**: 
    `SAP下发 -> WES接收 -> 打印条码 -> PDA绑定 -> RCS搬运 -> 上架完成 -> WMS扣账`
2.  **发料 (Issue)**: 
    `工单触发 -> WES波次计算 -> 锁定库存 -> 调度AGV/机械臂 -> 拣选 -> 送达产线 -> WMS扣账`
3.  **异常 (Exception)**: 
    `设备故障 -> WES重试(x3) -> 失败告警 -> 人工介入(PDA) -> 任务恢复 -> 完成`
