## 详细分解 (Detailed Breakdown)

### Epic 1: 存储优化策略引擎 (Storage Optimization Engine)
**描述**: 实现冷热区分析算法，生成移库建议，提升出入库效率。

#### US-E1-01: 冷热区分析算法
- **用户故事**: 作为 WES 系统，我需要定期分析物料的出库频次，以识别热料和冷料。
- **验收标准**:
  - [ ] 实现 `calculate_zone_level` 算法 (7天/30天频次)。
  - [ ] 支持可配置的阈值 (HOT_THRESHOLD)。
  - [ ] 每日凌晨 2:00 自动触发分析任务。
  - [ ] 输出物料热度分级结果 (HOT/COLD/NORMAL)。
- **故事点**: 5

#### US-E1-02: 移库任务生成器
- **用户故事**: 作为 WES 系统，我需要根据热度分级生成移库任务，优化存储分布。
- **验收标准**:
  - [ ] 识别 "热料在冷区" 和 "冷料在热区" 的异常。
  - [ ] 计算目标最优位置 (A面/B面)。
  - [ ] 调用 3.3.0 `Create_Task` 接口生成移库任务。
  - [ ] 限制每日生成任务数量不超过系统容量 5%。
- **故事点**: 8

#### US-E1-03: 策略配置管理 API
- **用户故事**: 作为管理员，我需要动态调整优化策略的参数。
- **验收标准**:
  - [ ] 提供 `POST /api/strategy/config`。
  - [ ] 支持修改热度阈值、任务生成上限。
  - [ ] 配置修改后即时生效。
- **故事点**: 5

---

### Epic 2: 全局负载均衡与编排 (Global Load Balancing & Orchestration)
**描述**: 实现跨区域的任务分配和死锁检测。

#### US-E2-01: 区域负载评估器
- **用户故事**: 作为调度系统，我需要实时计算各区域的负载指数。
- **验收标准**:
  - [ ] 聚合查询 3.3.0 的设备状态和队列长度。
  - [ ] 计算 `Load_Index`。
  - [ ] 提供内部 API 获取当前负载推荐值。
- **故事点**: 5

#### US-E2-02: 动态任务路由策略
- **用户故事**: 作为调度系统，我需要在任务创建时选择最优的执行区域/流水线。
- **验收标准**:
  - [ ] 拦截任务创建流程（作为 3.3.0 的插件/钩子）。
  - [ ] 基于 `Load_Index` 选择最优设备组。
  - [ ] 实现拥塞溢出逻辑 (Spillover)。
- **故事点**: 8

#### US-E2-03: 依赖死锁检测器
- **用户故事**: 作为调度系统，我需要监控任务间的资源锁定情况，防止死锁。
- **验收标准**:
  - [ ] 构建资源等待图 (Wait-for Graph)。
  - [ ] 定期 (5分钟) 运行 DFS 检测环路。
  - [ ] 发现死锁时，选择低优先级任务调用 3.3.0 `Cancel_Task`。
  - [ ] 触发死锁报警。
- **故事点**: 7

---

### Epic 3: 策略分析与报表 (Analytics & Reporting)
**描述**: 评估优化策略的效果。

#### US-E3-01: 优化效果追踪
- **用户故事**: 作为运营人员，我需要知道优化策略实际提升了多少效率。
- **验收标准**:
  - [ ] 记录移库任务的执行结果。
  - [ ] 统计优化后的出库路径缩短距离（估算）。
  - [ ] 生成每日优化报告。
- **故事点**: 5

#### US-E3-02: 策略执行日志 API
- **用户故事**: 作为开发人员，我需要查询策略执行的详细日志以便调试。
- **验收标准**:
  - [ ] 提供 `GET /api/strategy/logs`。
  - [ ] 支持按策略类型、时间筛选。
- **故事点**: 5
