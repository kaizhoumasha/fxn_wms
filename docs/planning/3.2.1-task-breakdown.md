## 概述 (Overview)

本文档基于详细设计文档 `3.2.1-dock-receiving-binding.md`，将功能需求分解为可评估的史诗故事 (Epic Stories) 和用户故事 (User Stories)。

**团队分工**:
- **WMS 团队** (内部): 全权负责当前阶段所有功能（业务逻辑、PDA 界面、SAP 集成、标签生成与打印）

**重要说明**: 根据 SRS.md §3.2.1，当前阶段由 WMS 全权负责，WES 不参与此阶段。WES 的标签渲染和自动打印服务属于"后续演进"选项，不在当前实施范围内。

**估算方法**: 使用标准 Fibonacci 序列 (1, 2, 3, 5, 8, 13, 21) 进行故事点估算

**总体规模**: 6 个 Epic，共 97 故事点

## Epic 1: 到货登记与清单管理 (Arrival Registration & Manifest Management)

**负责团队**: WMS
**总故事点**: 14
**优先级**: P0
**依赖**: 无

**Epic 描述**:
实现到货信息登记、物控清单导入、SAP GRN 单号请求等功能，为后续绑定操作提供数据基础。

### 用户故事 (User Stories)

#### US-E1-01: 到货信息登记 (Arrival Information Registration)

**作为** 仓库作业员
**我想要** 通过 WMS PDA 登记到货基本信息（车牌号/快递号、箱数）
**以便** 系统能够追踪入库货物

**验收标准** (Acceptance Criteria):
- [ ] PDA 界面支持选择运输方式（陆运/快递）
- [ ] 支持输入车牌号或快递号（必填，格式验证）
- [ ] 支持输入到货箱数（必填，>0）
- [ ] 支持输入备注信息（可选）
- [ ] 提交后生成唯一到货记录 ID
- [ ] 状态标记为 "待导入清单"
- [ ] 显示今日到货列表

**技术要点**:
- Blazor Server PDA 界面
- 表单验证逻辑
- 数据库插入操作
- 到货记录状态管理

**详细设计参考: [@docs/design/3.2.1 §3.3.1 到货登记页面](../docs/design/3.2.1-dock-receiving-binding.md#1-到货登记页面-arrival-registration-page)**

**故事点**: **2**
**估算理由**: 基础 PDA 表单 + 简单验证 + 数据库操作

---

#### US-E1-02: 到货清单导入 (Manifest Import)

**作为** 仓库管理员
**我想要** 从 Excel/CSV 文件导入物控到货清单
**以便** 系统能够获取详细的货物明细信息

**验收标准**:
- [ ] 支持上传 .xlsx 和 .csv 格式文件
- [ ] 提供清单模板下载功能
- [ ] 上传后自动解析并预览清单内容
- [ ] 显示清单明细表格（PO号、项次、料号、供应商、数量、批次、日期码）
- [ ] 执行格式校验（必填字段、数据类型、重复项检查）
- [ ] 显示校验结果和错误提示
- [ ] 校验通过后启用 "请求GRN" 按钮
- [ ] 支持选择关联的到货记录

**技术要点**:
- 文件上传组件
- Excel/CSV 解析库
- 数据验证引擎
- 预览表格组件
- 错误提示机制

**详细设计参考: [@docs/design/3.2.1 §3.3.2 到货清单导入页面](../docs/design/3.2.1-dock-receiving-binding.md#2-到货清单导入页面-manifest-import-page)**

**故事点**: **5**
**估算理由**: 文件解析 + 复杂验证逻辑 + 预览 UI + 错误处理

---

#### US-E1-03: SAP GRN 单号请求 (SAP GRN Request)

**作为** WMS 系统
**我想要** 根据导入的清单向 SAP 请求生成 GRN 单号
**以便** 货物能够正式登记到 SAP 系统

**验收标准**:
- [ ] 基于清单明细（PO + 项次 + 料号 + 数量）构建 SAP RFC 请求
- [ ] 调用 SAP RFC 接口请求 GRN 单号
- [ ] 处理 SAP 返回的 GRN 单号
- [ ] 更新到货记录，关联 GRN 与到货记录
- [ ] 显示 GRN 请求状态（待请求/请求中/已获取/失败）
- [ ] 支持请求失败后的重试机制
- [ ] 记录 SAP 交互日志

**技术要点**:
- SAP RFC 连接配置
- 异步请求处理
- 错误处理和重试逻辑
- 状态机管理
- 日志记录

**详细设计参考: [@docs/design/3.2.1 §3.1 单据接入](../docs/design/3.2.1-dock-receiving-binding.md#1-单据接入-order-ingest-sync--owner-wms-主账wes-仅接收副本)**

**故事点**: **5**
**估算理由**: SAP 集成 + 异步处理 + 错误恢复 + 状态管理

---

## Epic 2: 单据数据同步 (Order Data Synchronization)

**负责团队**: WMS

- [ ] 包含 `allow_mixed_pallet` 标志
- [ ] 记录数据同步日志（成功/失败）
- [ ] 更新 GRN 同步状态

**技术要点**:
- 数据库事务管理
- 幂等键生成算法
- 错误日志记录

**详细设计参考: [@docs/design/3.2.1 §3.1 单据接入](../docs/design/3.2.1-dock-receiving-binding.md#1-单据接入-order-ingest-sync--owner-wms-主账wes-仅接收副本)**

#### US-E3-05: 自动打印服务 (Auto-Printing Service)

**作为** WMS 系统
**我想要** 实现自动打印编排服务并在失败时回落到人工打印
**以便** 提高打印可靠性

**验收标准**:
- [ ] 实现打印机健康状态检查（TCP 连接测试）
- [ ] 选择可用的打印机（健康状态优先）
- [ ] 下发打印指令到打印机（TCP Socket）
- [ ] 实现重试机制（3次）
- [ ] 失败后自动回落到人工打印

## 风险与缓解措施 (Risks & Mitigation)

### 高风险项

1. **US-E4-03: PDA 箱条码扫描与 GRN 绑定 (8 点)**
   - 风险: 复杂的 M:N 绑定逻辑，用户体验要求高

   - 缓解: 提前验证 ZPL 库和打印机兼容性，准备备选方案

   - 风险: 打印机驱动可能不稳定或延期交付
   - 缓解: 提前明确驱动规范，准备 Mock 服务用于开发和测试

1. **US-E4-05: 混托物料类型兼容性校验 (5 点)**
