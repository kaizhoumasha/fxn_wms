# Playbooks — US3 异常兜底与演练

> Traceability: FR-005/FR-006/FR-009/US3；docs/SRS.md §3.7 系统控制与可靠性；Origin: docs/origin/休斯顿P9自动化仓库功能分解清单_202511021.xlsx（异常/性能条目，行号待补充）；历史峰值/事件日志（待采集）。

## 场景 1: RCS 设备不可用/拥塞
- **前置条件**: RCS 返回 ErrorCode=DeviceUnavailable/Congestion；任务 TaskID=...，TraceID=...
- **步骤**:
  1. WMS 记录异常并触发告警（P1）。
  2. 检查可用设备列表/地码，尝试改派（Retry N 次，间隔 Δt）。
  3. 改派失败则切换人工接管：RCS 任务取消/关闭；生成手工搬运单。
  4. 回写状态到 RCS/WMS 日志，保留 TraceID。
- **预期结果**: 任务成功改派或进入人工处理队列，状态可追溯。
- **回退条件**: 改派失败且无人工接管人力 → 保持告警，等待运维处理。

## 场景 2: 接口超时/失败（SAP/MES/RCS/WCS）
- **前置条件**: 接口调用超时/5xx；TraceID=...
- **步骤**:
  1. 记录失败及请求/响应摘要（不含敏感数据），写入重试队列。
  2. 按重试策略（指数退避 N 次）；仍失败则告警并转人工核对。
  3. 幂等键校验：避免重复落地（TaskID/CommandID/PO+LineItem/GRN）。
  4. 成功后回写状态并清理队列。
- **预期结果**: 可自动恢复或清晰落地人工处理。
- **回退条件**: 重试全部失败 → 人工核对/补录。

## 场景 3: 库容超限/锁定失败
- **前置条件**: 库容检查失败或库存锁冲突。
- **步骤**:
  1. 标记异常库存/位置为锁定状态；通知操作员。
  2. 提供替代储位建议（同区域/同料型）或暂存缓冲区。
  3. 若仍失败，转人工确认并记录 TraceID。
- **预期结果**: 不发生撞库/错放；有替代路径或人工确认。
- **回退条件**: 无可用储位 → 暂存+告警。

## 观测与记录
- **指标**: 改派成功率、接口失败率、重试成功率、人工接管耗时。
- **日志/字段**: TraceID/CorrelationID、TaskID/CommandID、ErrorCode、RetryCount、Operator。
- **告警**: 超过阈值触发 P1（接口成功率<99%、RCS 改派失败率上升等）。
