  退料场景
   * 触发时机:
       * 工单结单 (WO Completion): 生产结束，剩余物料需退库。
       * 工单切换 (Changeover): 换线生产其他产品。
       * 工程变更 (ECO) 或 质量异常: 需冻结或退回特定物料。
   * 物理对象:
       * 料盘 (Reel): 已拆封或未拆封的电子元器件。
       * 退料标准胶框（Bin）：退料时，将料盘放入标准胶框。
       * 单层货架: 用于存放`退料标准胶框`, 并使用 AGV运送；
       * 退货货架 (Return Rack): 专用的 A/B 面货架，支持按料盘级精细化管理。
   * 工人操作:
       * 产线工人从飞达上拆除料盘，扫描料盘 PKG 码后放入退料标准胶框。（确认退料工单、是否不良品换料、是否满盘物料）
       * 注：MSD 物料需要将料盘装回原封装袋中；
       * 产线工人在产线退料完成后，将退料标准胶框放上`单层货架`, 人工呼叫 AGV 搬运往`仓库退料作业区`
       * `仓库退料作业区`工人在接收到产线上退回的`单层货架`, 从`退料标准胶框`中逐盘取出料盘，进行分类：
       * 分类策略:
           * 电子料 (Electronic): 进入自动化流水线（后续接 LCR/X-Ray）。
           * MSD / 非规则: 无法上自动线, 放入其他胶框, 走人工处理。
           * 高值物料 (High-Value): 标记专人点收，走高值区流程。
   * LCR 测试:
       * 自动化流水线前，工人扫描料盘 PKG 码，确认是否需要 LCR 测试料盘。
       * 决策逻辑:
           * 若物料为整盘则免测。
       * LCR 执行: 
           * Pass/免测: 放入自动化流水线。
           * Fail: 剔除至不良品框，WES 标记为 Defective，不入良品库。
   * X-Ray:
       * 流水线将料盘送入 X-Ray 设备， 设备读取料盘 PKG 码，确认是否需要 X-Ray 点数。
       * 决策逻辑:
           * 若物料为整盘则免点。
       * X-Ray 执行: 
           * 免点: 跳过 X-Ray 设备，进入后续步骤。
           * 点数: X-Ray 设备执行点数，结果返回给 WES（含 PKG 码，点数结果），WES 生成新的 PKG 码，回传给 X-Ray 设备, X-Ray 设备打印新的 PKG 标签并贴上，之后进入后续步骤；
       * 机械臂操作:
           * 扫描到达机械臂工作位的料盘 PKG 码，发送扫描结果给 WES。
           * 验证退料 PKG 码是否正确；
           * 决策逻辑:
               * 正确:  WES 返回退料货架上可存储 SLOT 码，机械臂夹手抓取料盘，并放入指定 SLOT。
               * 错误:  机械臂夹手抓取料盘，并放入 NG 框。

   6. 与 GRN 信息进行匹配关联（单 GRN 直接关联，多 GRN 需要让工人选择）
   7. 栈板工作完成后，调度 RCS；
     * 决策逻辑: 贵重料直接送入贵重仓（IQC 取样由工作人员在贵重仓内完成）；其他物料送入暂存区；
   8. 码头环节有可能漏扫箱号，需要提供栈板上箱号补录功能，在后续环节补充栈板与箱号的绑定关系（优先级 P2）

2. 拆板作业：
  **工作人员**可根据需要，对栈板上的料盒进行拆板：
  * **工作人员**扫描原栈板号，以及新栈板号，从原栈板上搬下需要拆板的料盒，并逐盒扫描箱码，将其从原栈板上解绑后绑定到新栈板上。如有需要，**工作人员**还需要将新栈板与地码进行绑定，以便后续 RCS 作业
  * 拆板作业可在 `栈板暂存区`, `IQC 复判区`, 以及后续的 `收货验收区`使用。

3. 暂存区与 IQC
   1. 栈板到达暂存区后，即显示到 IQC `待检列表`（PC WEB）中（按 GRN 进行显示，GRN 与栈板是多对多的关系，点击某 GRN 可展开该GRN 下的栈板信息）；
   2. 同时请求 QMS 获取抽检规则，获取抽检数量；
     * ~~QMS 是否支持`料号、供应商、数量`获取抽检数量？还是必须有 GRN 后才能从 QMS 获取抽检数量？**（待定）**~~；
     * 决策逻辑: 按 GRN 请求 QMS，若某 GRN 抽检数量为 0 时，直接标注该 GRN 为免检；
   3. `待检列表`中默认按栈板到达暂存区时间排序，IQC 主管/人员 可对`待检列表`中的 GRN 调整优先级，优先级高的居前显示；
   4. IQC 人员从`待检列表`调用 RCS 从暂存区呼叫栈板（自动、手动模式）；
     * 注：需要配置 IQC 待检区栈板容量，当下达的RCS 任务数量超过配置容量时，RCS 需要处理排队（还需要考虑到急料插队）；
     * 决策逻辑: 1 个栈板可对应多个 GRN，1 个 GRN 又可存放在多个栈板上；
     * 自动模式下，优先调用满足多个 GRN IQC 检测任务的栈板；
     * 手动模式下，当工作人员选择某 GRN 时，且该 GRN 有多个栈板时，显示该 GRN 所在的所有栈板信息，可手动选择调用的栈板（若某栈板已在 IQC 待检区，优先推荐）；
   5. IQC 取样：**IQC 人员**在 IQC 待检区，使用 PDA 先扫描栈板号，显示出该栈板上的 GRN 待检信息，~~再扫描要开箱的箱号(确认是否需要扫描箱号)~~，然后再**逐盘**扫描对应物料 PKG 码，直至达到 QMS 要求的抽检数量；
   6. IQC 检测完成（**轮询 QMS 获取检测结果**）：
     * 任务检查*: 系统优先判断该栈板上是否还有其他 GRN 待检。若有，提示继续取样；若无，执行以下判定：
     * 决策逻辑: 
       - ANY NG: 将 GRN 标记为 `需复判`，同时检查**当前栈板是否还有未完成的 IQC 任务**，如无：下发 RCS 任务将该栈板搬入复判区，**同时需要所有涉及该 GRN 的栈板（含暂存区的栈板）标注为 `需复判`**等待复判人员处理；
       - ALL OK: 将该栈板上已检测的 GRN 标记为 `通过`，同时检查**当前栈板是否还有未完成的 IQC 任务**，如无，下发 RCS 任务将栈板搬入暂存区；
   7. IQC 归还：**IQC 人员**在检测完成后，需要将取样的物料还回原栈板中，首先使用 PDA 先扫描栈板号，然后再**逐盘**扫描对应物料 PKG 码，直到所有物料都还回原栈板中；当所有物料归还栈板后，根据 2.5 的决策，调用 RCS 执行搬运任务；
   8. 复判作业：
   **IQC 人员**对复判区对物料进行复判,在 QMS 系统中录入复判结果:
     - **复判 OK**: 更新 QMS 判定结果为 OK，调用 RCS 将栈板移回 `栈板暂存区`
     - **复判 NG**: 更新 QMS 判定结果为 NG，系统自动搜索`栈板暂存区`、`IQC 待检区`内所有包含该 GRN
         的栈板，将其状态锁定（不可呼叫至收货区）。需要拆板作业，**拆板完成**后，**IQC 人员**手动调用 RCS 将栈板（验证栈板上的物料都是 OK 的）移回 `栈板暂存区`。同时，如果`栈板暂存区`内有相同 GRN 的 NG 物料，还需要指导 **IQC 人员**从 `栈板暂存区` 中拆除 `复判 NG` 物料（~~需要确定是在 `栈板暂存区`内作业还是由 RCS 将栈板叫出作业~~）。

4. `收货验收区`中增加 `电子料（SMT、MSD、异形料）待收列表` PC端页面，显示 IQC 已完成（含免检）的栈板；
   * `待收列表` PC端页面，按 `栈板到达时间` 排序，**工作人员** 可主动修改优先级；
   * **工作人员** 从`待收列表`调用 RCS 从 `栈板暂存区` 呼叫 RCS 运送`电子料（SMT、MSD、异形料）`栈板（自动、手动模式）；
      * 系统预判与拆板:
        * 栈板到位后，**工作人员** 扫描 `收货验收区` 到位的栈板号，PDA 自动提示该栈板是否包含 非标准盘（非7/13/15寸）、MSD 物料。
        * 若包含，要求工作人员执行 拆板作业。可将标准盘保留在原栈板，将非标物料移至新栈板；也可将非标物料保留在原栈板，将标准盘移至新栈板。
      * 分流处理:
        * 流向 A (标准盘): 使用地牛将只承载 7/13/15 寸物料的栈板送到 粗分机拆箱工作位（进入 Section 5）。 
        * 流向 B (MSD/异形料):
           * 工作人员通过 PDA 呼叫 RCS 将承载 MSD/异形料 物料的栈板送入 `SMT 手工注册/作业区`。
           * 在手工区，工作人员逐个开箱、逐个/盘扫描 PKG 码，完成系统入库绑定。

5. `粗分机拆箱工作位` 上， **工作人员** 通过 PDA 扫描 接收到的栈板，并执行 `SMT 拆箱作业`。
